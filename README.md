# 2048
enjoy mini game!

## 使用指南
### 第一步：下载[源码](https://github.com/AASWEETBOY/2048/blob/main/2048.c)

### 第二步：编译运行
Linux命令
```
gcc -o 2048 2048.c && ./2048
```

Windows命令
```
cl 2048.c /Fe:2048.exe && 2048.exe
```
